# 🎨 Digit Classifier AI - Frontend

An interactive web app where users can draw digits (0–9) and get real-time predictions powered by a CNN-based AI backend.

---

## 🚀 Demo

### ✍️ Draw & Predict
![App Preview](public/demo.png)

---

## ⚡ Features

- 🎨 Canvas drawing interface (mouse + touch)
- ⚡ Real-time prediction using FastAPI backend
- 📊 Probability bars for all digits (0–9)
- 🎯 Top prediction + confidence score
- 🧠 Powered by CNN model (99%+ accuracy)

---

## 🛠️ Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- Fetch API (connects to FastAPI backend)
